# 🚀 JavaScript Final Assessment - Dicoding

Sebuah repositori yang berisi penyelesaian tugas akhir dan evaluasi pembelajaran dari kelas JavaScript. Proyek ini mendemonstrasikan penguasaan logika fundamental pemrograman, arsitektur kode, hingga pengujian otomatis (*automated testing*).

## 🛠️ Tech Stack & Tools
* **Language:** JavaScript (ES6+)
* **Environment:** Node.js
* **Testing Framework:** Native Node.js Test Runner (`node:test` & `node:assert`)

## 📦 Modul & Fitur yang Diselesaikan

Repositori ini mencakup penyelesaian kasus-kasus berikut:

1. **Fundamental Logic & Clean Code**
   * Menerapkan praktik penulisan komentar yang baik.
   * Merapikan gaya penulisan kode (*code style*) sesuai standar industri.

2. **Automated Unit Testing**
   * Menyusun skenario pengujian menggunakan metode *Arrange-Action-Assert* (AAA).
   * Mencapai **100% Full Coverage Testing** pada logika percabangan fungsi matematika.

3. **Object-Oriented Programming (OOP)**
   * Merancang arsitektur Sistem Manajemen Inventaris menggunakan ES6 Classes.
   * Mengelola *state* dan *behavior* dari objek `Item` dan `Inventory`.

4. **Algoritma Rekursif (Recursive)**
   * Memecahkan masalah matematika tanpa *looping* konvensional.
   * Mengimplementasikan fungsi pencarian nilai **Faktorial** dan generasi **Deret Fibonacci**.

5. **Real-World Scenario: Restaurant Order API**
   * Membangun logika bisnis untuk manajemen pesanan restoran.
   * Manipulasi struktur data Array of Objects tingkat lanjut menggunakan *Higher-Order Functions* (`.map()`, `.filter()`, `.reduce()`, `.find()`).
